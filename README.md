Указатели:

* - это значения по адресу указателя (разыименовывание), 
& - это адрес в памяти

1) int a = 10; *&a = a; OK  &*a = a; Error
2) Значение адреса (*) можно узнать только у указателя или итератора
3) Адрес (&) можно узнать как у указателя так и у переменной

4) Все укзатели одного размера - 8 байт
5) Указатель - это переменная, которая хранит адрес в памяти.
6) Адрес - это просто целое число, которое показывает, где  памяти находится переменная

int a = 10;
&a = 0x7ffcb5017a3c
int* ptr_a = &a;
|
|---- *ptr_a = 10 значение по адресу указателя
|---- &ptr_a = 0x7ffcb5017a40 адрес в памяти на указатель
