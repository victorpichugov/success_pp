# Задача на сегодня (лёгкая): Максимальная прибыль 📈

> Одна покупка и одна продажа. Идеально, чтобы закрыть день без тяжёлой математики.

## Условие

Дан массив `prices`, где `prices[i]` — цена акции в `i`-й день.

Ты можешь купить акцию **один раз** и продать её **один раз** (продажа строго после покупки).
Найди максимальную прибыль, которую можно получить.

Если прибыль получить невозможно — верни `0` (просто не совершать сделку).

### Примеры

```
prices = [7, 1, 5, 3, 6, 4]   →  5     (купить за 1 на 2-й день, продать за 6 на 5-й: 6 - 1 = 5)

prices = [7, 6, 4, 3, 1]      →  0     (цены только падают — сделки не делаем)
```

### Ограничения

- `1 <= prices.length <= 10^5`
- `0 <= prices[i] <= 10^5`

## Подсказки (читай, если застрял)

<details><summary>Подсказка 1</summary>

Наивный вариант: две вложенные циклы — для каждой пары (покупка, продажа) считаем разницу.
Сколько это по времени? (Подсказка: O(n²). А ограничения до 10^5 — хватит ли?)

</details>

<details><summary>Подсказка 2</summary>

Ходи по массиву слева направо **один раз**. В любой момент, когда мы смотрим на `prices[i]`,
прибыль от продажи **сегодня** = `prices[i] - минимальная цена, которую мы уже видели`.
Держи два числа: «минимум пока» и «лучшая прибыль пока».

</details>

<details><summary>Подсказка 3</summary>

Порядок внутри цикла: сначала сравни `prices[i]` с текущим минимумом через прибыль,
**потом** обнови минимум. Или наоборот — подумай, почему оба порядка сходятся (покупка в тот же
день даёт прибыль 0).

</details>

## Решение (спойлер — читай только после своего решения)

<details><summary>Решение O(n)</summary>

```cpp
int maxProfit(vector<int>& prices) {
    int minPrice = prices[0];      // лучшая цена для покупки «пока»
    int best = 0;                  // лучшая прибыль «пока»

    for (int price : prices) {
        best = max(best, price - minPrice);   // продать по текущей цене
        minPrice = min(minPrice, price);      // или купить по текущей цене
    }

    return best;
}
```

- **Время:** O(n) — одна переобход.
- **Память:** O(1).

Ключевая мысль: в момент, когда мы смотрим на `prices[i]`, лучшая сделка с продажей **в этот день**
— купить по минимальной цене, которая была **до** этого дня. Всё, что нам нужно помнить, — одно
число (минимум), а не весь прошедший префикс.

</details>
